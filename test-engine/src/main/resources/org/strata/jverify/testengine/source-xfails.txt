# Per-class xfail overrides for the SOURCE frontend -- the counterpart of the
# bytecode frontend's bytecode-xfails.txt, read by JVerifyTestEngine through
# SourceXfailManifest. Same format:
#
#   XFAIL <fqcn> <BLOCKER> <reason>   run the fixture but invert its outcome (XPASS
#                                     trips when it starts passing: delete the entry)
#   RUN   <fqcn> <reason>             run an annotation-level expectedToFail fixture
#
# A fixture's @JVerifyTest expectations describe what a CORRECT frontend produces.
# Where only one frontend falls short, the exception lives in that frontend's own
# manifest, so the shared corpus is never bent to the weaker output.
